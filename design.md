# UI/UX Design Prompt for Smart Dossier

**Tool:** Use this prompt in your preferred AI UI generator (e.g., v0, Midjourney, Stitch) or hand it to a designer.

---

## The Prompt

**Project Overview:**
Design a breathtaking, premium web application interface for a government/enterprise "Smart Dossier" management system. The platform is used by civil servants to track property expropriation workflows, but it needs to look like a high-end, luxury fintech or exclusive dashboard.

**Color Palette & Vibe (The "Rolex" Aesthetic):**
- **Primary Color:** Deep "Rolex" Forest Green (`#006039` or similar deep emerald).
- **Accents:** Champagne Gold (`#D4AF37` or `#F3E5AB`) for critical call-to-actions, borders, and active states.
- **Backgrounds:** A sleek, deep dark mode (Charcoal / Obsidian Black) to make the green and gold pop, utilizing glassmorphism (frosted glass) panels for depth.
- **Typography:** Modern, sophisticated sans-serif (e.g., Inter, Outfit, or Roobert) with high contrast.

**Key Visual Features & Interactions:**
1. **Dynamic Scroll Highlighting:** As the user scrolls down the page or reads through a long property document, the key points, dates, and amounts should smoothly highlight themselves (in subtle gold) linked to the scroll position.
2. **Mouse-Follow Effects:** Implement a glowing cursor effect where a soft emerald or gold radial gradient follows the user's mouse behind the glassmorphic cards, illuminating the edges of the UI elements as the mouse passes over them.
3. **3D Hero/Background Elements:** Where possible (especially on the login screen or dashboard empty states), include insane, high-fidelity 3D abstract topographical maps or floating 3D geometric shapes (glass and dark metal) that slowly rotate.
4. **Data Visualization:** The Kanban board (Dossier Board) and timeline steppers should look ultra-premium. Cards shouldn't just be white boxes; they should be dark, translucent panels with thin golden/green borders that glow on hover.

**Page to Generate:**
The main "Dossier Dashboard". 
- Left sidebar: Sleek navigation icons.
- Center area: A detailed timeline/stepper showing the current phase of a property dossier. Below it, a list of uploaded documents.
- Right panel (AI Assistant): A glassmorphic chat interface powered by Gemini API, showing a summary of the property with a floating, pulsing 3D orb indicating AI status.

**Vibe Check:** Think "Succession", "Luxury Swiss Watchmaker", and "Next-Gen AI Platform" combined. It must absolutely wow the user at first glance.
