# Project Overview

## Vision & Tagline
**Smart Dossier** — AI-powered platform for managing Albanian property procedures.

## Target Audience
- **Primary Users:** Albanian Civil Servants (e.g., from Bashkia, ALUIZNI, Ministria e Financave).
- **Secondary Users:** Citizens (for read-only, anonymous dossier status tracking).

## Problem Statement
Property procedures in Albania involve multiple institutions, strict deadlines, and heavy documentation. Tracking these procedures manually leads to bottlenecks, expired deadlines, and misplaced documents.

## The Solution
Smart Dossier provides a centralized, AI-enhanced Kanban-style dashboard for civil servants. It leverages:
- **AI Document Extraction:** Automatically reads uploaded physical documents (via OCR) and extracts required fields to eliminate manual data entry.
- **Smart Summarization:** AI reads through hundreds of pages of case logs and provides a 4-sentence Albanian summary of the dossier's current state.
- **Actionable Insights:** Predicts the next necessary step based on missing documentation and current procedural phase.
- **Automated Alerts:** Triggers warnings when files block or deadlines approach.
- **RAG Q&A Assistant:** A contextual chatbot that answers complex procedural queries strictly grounded in Albanian law documents.

## Scope
For the initial release (Innovation4Albania Hackathon), the platform models two specific property processes:
1. **Shpronësimi (Expropriation)** - A 7-phase procedure.
2. **Privatizimi EKB (EKB Privatization)** - A 5-phase procedure.
