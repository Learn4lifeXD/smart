# System Architecture

## Technology Stack

- **Frontend Framework:** Next.js 14 (App Router) with TypeScript.
- **Styling:** Tailwind CSS + shadcn/ui.
- **Backend & Database:** Supabase (PostgreSQL, Auth, Storage, Edge Functions, Realtime).
- **AI Models:** Google Gemini (`gemini-1.5-flash` for extraction/summary/alerts, `gemini-1.5-pro` for formal letter generation, `text-embedding-004` for vectors).
- **Vector Store:** Supabase `pgvector`.
- **OCR Pipeline:** Tiered fallback system: `pdf.js` (text layer) &rarr; `Tesseract.js` (WASM) &rarr; `PaddleOCR` (Docker microservice).

## Database Schema (PostgreSQL)

The core relational data is structured across 7 main tables:
1. `dossiers`: Core procedural records tracking phase, owner, and property metadata.
2. `phase_logs`: Complete audit trail of transitions between procedural phases.
3. `documents`: File metadata, OCR extracted raw text, and structured AI fields.
4. `alerts`: System-generated warnings (deadline, blockage, missing documents).
5. `generated_letters`: Formal state documents generated by `gemini-pro`.
6. `knowledge_chunks`: pgvector embeddings of Albanian legal laws for RAG chat.
7. `ai_interactions`: Logs for all LLM prompts/responses to ensure auditability.

## Supabase Edge Functions

AI logic is isolated in stateless Deno Edge Functions to keep the frontend light and secure API keys:
- `ai-summary`: Fetches dossier context and generates a quick 4-sentence overview.
- `ai-next-step`: Compares uploaded documents against JSON process definitions to determine the missing action.
- `ai-extract`: Parses OCR text and extracts structured JSON fields.
- `ai-chat`: Queries `pgvector` knowledge chunks to answer legal questions.
- `ai-alerts`: Scans all active dossiers for impending deadlines or blockages.
- `generate-letter`: Generates formal administrative letters using `gemini-pro`.

## OCR Microservice Architecture

In order to remain entirely open-source and free, Smart Dossier avoids paid OCR APIs by using a waterfall mechanism:
1. **Client-side PDF Layer:** If the file is a digital PDF, text is extracted instantly via `pdfjs-dist`.
2. **Client-side WASM OCR:** If the file is an image, `tesseract.js` runs directly in the browser.
3. **Server-side PaddleOCR:** For heavily degraded scans, a lightweight Python FastAPI Docker container runs `PaddleOCR` for high-accuracy text recognition.
